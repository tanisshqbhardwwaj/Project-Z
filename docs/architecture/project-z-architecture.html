Shared path after the device: middleware → JWT → org header → /api/v1 → services → Prisma → Turso.

1. Website

Chrome / Edge on a laptop or shop PC. No APK, no .exe. The browser is only a thin client.

Figure 1 — Website. Online-first. Same APIs as the other two clients.

2. Android app

Capacitor wraps the same Next UI in an APK. Shop writes can go to the phone first, then sync when the network is back.

Figure 2 — Android. Device SQLite is a cache + outbox. Turso wins after sync.

3. Windows

Tauri .exe. Same React UI in a desktop WebView. Local SQL on the PC, not Capacitor SQLite.

Figure 3 — Windows. Desktop shell + local SQL. Same cloud as the website and the phone.

4. All in one

Three clients. One API. One database. Files and jobs sit beside it, not inside Turso.

Figure 4 — All in one. Do not put photos in Turso. Do not give the phone a direct database URL.
